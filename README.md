# Вьетнам 2026 — вторая версия

Сайт-приглашение в поездку по Вьетнаму: Камрань → Далат → Фанранг, ноябрь–декабрь 2026.

**Онлайн:** https://trunchez.github.io/vietnam-2026-v2/  
**Исходники:** https://github.com/Trunchez/vietnam-2026-v2

## Что внутри

- полноэкранный кинематографичный первый экран;
- манифест с личным текстом и фотографией;
- горизонтальный маршрут из трёх городов, который листается скроллом;
- архив фотографий с перетаскиванием и просмотром;
- 3D-карточка участника MWR Life и честный блок про условия;
- FAQ, контакт с WhatsApp и телефоном.

## Технически

Чистый HTML, CSS и ванильный JavaScript. Без сборки, фреймворков и внешних библиотек. Шрифты Unbounded, Onest и JetBrains Mono лежат локально. Фотографии — из личного архива Максима.

Открыть локально:

```bash
python -m http.server 4174
```

и зайти на `http://127.0.0.1:4174/`.

## Забрать себе

Можно скачать ZIP через кнопку **Code → Download ZIP** в репозитории или сделать форк. Сайт статический: достаточно положить папку на любой хостинг.
